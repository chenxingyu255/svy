# ☕ 云餐宝 —— 智慧餐饮点餐与门店管理系统（源代码项目）

> 一份开箱即用、零依赖、纯前端实现的餐饮门店数字化管理系统源代码。
> 双击 `index.html` 即可在浏览器中运行演示，无需安装任何环境。

---

## 一、项目名称

**云餐宝（YunCanBao）智慧餐饮点餐与门店管理系统**

## 二、语言技术

| 类别 | 内容 |
| --- | --- |
| 前端语言 | HTML5、CSS3、原生 JavaScript（ES6+，含 SVG 图表） |
| 后端 | 无后端，数据存储于浏览器 `localStorage` / `sessionStorage` |
| 依赖与构建 | **零第三方依赖、零构建步骤**，直接打开即用 |
| 运行环境 | 现代浏览器（Chrome / Edge / Firefox 等），支持静态托管部署 |
| 工程结构 | 多文件模块化（utils / store / auth / menu / cart / orders / tables / dashboard / app） |

## 三、系统类型

- **B/S 架构单页应用（SPA）**：浏览器端运行，页面无刷新切换。
- 数据层为轻量级本地持久化（localStorage），可导入 / 导出 JSON 备份。
- 适合作为课程设计、毕业设计、外包演示、门店数字化样板项目。

## 四、行业分类

- 餐饮 / 生活服务 / 门店数字化（SaaS 轻量版）
- 细分领域：中式正餐、快餐简餐、小吃饮品等中小餐饮门店

## 五、行业场景（立项原因与业务背景）

> 本段不少于 40 个中文字符。

传统中小餐饮门店普遍存在手写菜单效率低、下单易出错、人工记账难以统计、桌台与订单状态混乱、缺乏经营数据支撑等痛点。**立项原因**：为解决餐饮门店“点餐-收银-后厨-统计”全流程数字化问题，降低门店运营成本并提升翻台效率。**行业场景**：面向快餐店、家常菜馆、奶茶小吃店等中小型餐饮商户，在收银台、后厨、包间多端协作场景下完成堂食点餐、订单流转与经营分析。**业务背景**：数字化点餐已成为餐饮行业降本增效的刚需，本项目以轻量化、免部署、低成本的方式提供一套可落地的门店管理解决方案。

## 六、功能介绍

> 本段不少于 80 个中文字符。

本项目包含以下具体功能模块：

1. **用户认证模块**：支持登录、注册、退出，内置管理员与店员两种角色，具备角色权限控制（普通店员不可删除菜品、不可进入系统设置）。
2. **菜单管理模块**：菜品的增删改查、分类管理、上下架、价格与库存维护、销量累计、搜索与分类筛选。
3. **点餐与购物车模块**：菜品一键加入购物车、数量增减、删除，实时计算合计金额，支持填写备注。
4. **桌台管理模块**：桌台的新增、座位数配置、状态（空闲/就餐中/待结账）流转、一键清空、桌台历史订单查看。
5. **订单管理模块**：从购物车选择桌台下单，订单状态机流转（待支付→制作中→已完成，可取消），订单筛选与详情展示，支持导出订单 JSON。
6. **经营看板模块**：今日营业额、今日订单数、进行中订单、累计销量等核心指标卡片，以及热销菜品 TOP5 柱状图、分类销量占比环形图（手写 SVG，无图表库）。
7. **系统设置模块**：店铺名称、公告、营业状态维护，账号密码修改，数据导出 / 导入 / 一键恢复初始演示数据。

项目主要功能描述：以“点餐 → 下单 → 制作 → 结账 → 统计”为主线，为餐饮门店提供从菜品展示、购物车结算、桌台与订单流转到经营数据可视化的一体化管理能力，同时支持多角色权限和数据备份恢复，兼顾演示效果与实际可用性。

## 七、项目实现

> 本段不少于 40 个中文字符。

**“我”负责的任务**：需求分析、原型设计、UI 视觉设计、全部前端代码开发（页面结构、样式系统、九个 JS 模块）、数据模型设计、订单状态机设计、SVG 图表绘制、文档编写与演示部署指导。

**技术线**：原生 HTML5 + CSS3 + JavaScript（ES6），localStorage 持久化，SVG 手绘图表，事件委托与防抖优化。

**架构**：模块化分层——工具层（utils）、数据层（store）、业务模块层（auth/menu/cart/orders/tables/dashboard）、控制层（app），各模块通过全局对象解耦，主控制模块统一调度渲染。

**实现亮点**：① 零依赖零构建，开箱即用；② 数据层统一封装，支持导入导出与一键重置；③ 手写 SVG 柱状图与环形图，无第三方库；④ 角色权限控制；⑤ 响应式布局与中文友好交互。

**难点**：① 前端数据一致性与状态同步（下单后同时更新订单、桌台、销量、库存多处数据）；② 订单状态机的边界处理（取消订单后桌台释放逻辑、进行中订单保护）；③ 无后端条件下的多端协作模拟与数据备份恢复；④ 环形图路径（弧线）的数学计算与动态生成。
